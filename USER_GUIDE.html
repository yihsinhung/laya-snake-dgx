重開機後恢復After a reboot

venv 與權重在磁碟上,重開機不會消失,所以不用重裝,只需恢復執行。 The venv and weights live on disk, so a reboot does not wipe them; just resume, no reinstall.

執行蛇的各種方式Ways to run the snake

# 互動,12 FPS(人眼看清楚)interactive, 12 FPS
~/laya-snake-dgx/run_snake.sh

# 互動,全速(~75 steps/s)interactive, full speed (~75 steps/s)
~/laya-snake-dgx/run_snake.sh --max-speed

# 無頭 benchmark,600 步自動停headless benchmark, 600 steps
~/laya-snake-dgx/run_snake.sh --headless --steps 600 --max-speed

# 換模型:英文 421M(預設多語 322M)switch to English 421M (default multilingual 322M)
~/laya-snake-dgx/run_snake.sh --max-speed --model convaiinnovations/laya

# 完整效能測試full benchmark sweep
~/laya-snake-dgx/run_snake.sh benchmark --rates 30 --sweep-steps 100 \
  --seeds 101,102 --output ~/laya-snake-dgx-work/bench.json
